# Clanker

Clanker is an AI companion that runs on your own computer: a 3D character you talk to, who answers out loud,
tells jokes, checks the weather, searches the web, plays music, sets timers and remembers you.

This repository only holds the **released installers and update packages**. Get the newest version from
[Releases](../../releases/latest):

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `Clanker-Setup-X.Y.Z.exe` |
| macOS 14 Sonoma or newer | `Clanker-mac-X.Y.Z.tar.gz` |
| Linux (64-bit x86) | `Clanker-linux-X.Y.Z.tar.gz` |

`clanker-app-X.Y.Z.zip` is the update package: an installed Clanker downloads it by itself
(UX Settings > Updates) and keeps your conversations, memories and settings.
`SHA256SUMS.txt` lists the checksums of every file.

Note: the AI model is an uncensored version of Google's Gemma 4. It can say rude or dark things.
